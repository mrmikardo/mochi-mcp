# mochi-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a FastMCP server that wraps the Mochi Cards API, exposing 4 read-only tools for decks and cards, packaged with `uv` for `uvx` distribution.

**Architecture:** A `src/` layout Python package with three modules: `client.py` (httpx-based API client with transparent pagination), `tools.py` (FastMCP tool registration via `register_tools(mcp, client)`), and `server.py` (creates both instances and wires them together). Note: `register_tools` takes an explicit `client` parameter for testability — the spec describes module-level client instantiation but this pattern is cleaner.

**Tech Stack:** Python 3.11+, FastMCP ≥ 2, httpx, pytest

import httpx

BASE_URL = "https://app.mochi.cards/api/"


class MochiClient:
    def __init__(self, api_key: str, transport: httpx.BaseTransport | None = None) -> None:
        self._http = httpx.Client(
            base_url=BASE_URL,
            auth=(api_key, ""),
            transport=transport,
        )

    def _get(self, path: str, params: dict | None = None) -> dict:
        try:
            response = self._http.get(path, params=params or {})
            response.raise_for_status()
            return response.json()
        except httpx.HTTPStatusError as e:
            raise Exception(
                f"Mochi API returned {e.response.status_code}: {e.response.text}"
            ) from e

    def get_deck(self, deck_id: str) -> dict:
        return self._get(f"decks/{deck_id}")

    def get_card(self, card_id: str) -> dict:
        return self._get(f"cards/{card_id}")

    def list_decks(self) -> list[dict]:
        raise NotImplementedError

    def list_cards(self, deck_id: str | None = None) -> list[dict]:
        raise NotImplementedError
```

    def list_decks(self) -> list[dict]:
        results: list[dict] = []
        params: dict = {}
        while True:
            data = self._get("decks", params=params)
            docs = data.get("docs", [])
            results.extend(docs)
            bookmark = data.get("bookmark")
            if not docs or not bookmark:
                break
            params = {"bookmark": bookmark}
        return results

    def list_cards(self, deck_id: str | None = None) -> list[dict]:
        results: list[dict] = []
        params: dict = {}
        if deck_id:
            params["deck-id"] = deck_id
        while True:
            data = self._get("cards", params=params)
            docs = data.get("docs", [])
            results.extend(docs)
            bookmark = data.get("bookmark")
            if not docs or not bookmark:
                break
            params = {**params, "bookmark": bookmark}
        return results
```

from mochi_mcp.client import MochiClient


def register_tools(mcp, client: MochiClient) -> None:
    @mcp.tool
    def list_decks() -> list[dict]:
        """List all Mochi decks."""
        return client.list_decks()

    @mcp.tool
    def get_deck(deck_id: str) -> dict:
        """Get a single Mochi deck by ID."""
        return client.get_deck(deck_id)

    @mcp.tool
    def list_cards(deck_id: str | None = None) -> list[dict]:
        """List all Mochi cards, optionally filtered by deck ID."""
        return client.list_cards(deck_id=deck_id)

    @mcp.tool
    def get_card(card_id: str) -> dict:
        """Get a single Mochi card by ID."""
        return client.get_card(card_id)
```

import os
from fastmcp import FastMCP
from mochi_mcp.client import MochiClient
from mochi_mcp.tools import register_tools


def main() -> None:
    api_key = os.environ.get("MOCHI_API_KEY")
    if not api_key:
        raise ValueError("MOCHI_API_KEY environment variable is required")

    client = MochiClient(api_key=api_key)
    mcp = FastMCP("mochi-mcp")
    register_tools(mcp, client)
    mcp.run()


if __name__ == "__main__":
    main()
```

# mochi-mcp

MCP server for the [Mochi Cards](https://mochi.cards) API. Provides read access to your decks and cards.

## Tools

| Tool | Description |
|------|-------------|
| `list_decks` | List all your Mochi decks |
| `get_deck` | Get a single deck by ID |
| `list_cards` | List all cards (optionally filtered by `deck_id`) |
| `get_card` | Get a single card by ID |

## Setup

### Claude Desktop

Add to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "mochi": {
      "command": "uvx",
      "args": ["mochi-mcp"],
      "env": { "MOCHI_API_KEY": "your-api-key-here" }
    }
  }
}
```

Your Mochi API key is in [Mochi Settings → API](https://app.mochi.cards/settings).

### Development

```bash
uv sync
MOCHI_API_KEY=your-key uv run mochi-mcp
```

## Requirements

- Python 3.11+
- A [Mochi Cards](https://mochi.cards) account and API key
```
